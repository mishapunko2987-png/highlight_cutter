# Нарезка фильмов

Мобильное приложение (Android + iOS) которое само находит лучшие моменты фильма
и нарезает из них клипы или трейлер.

## Как это работает

1. **Анализ кадров.** Видео разбирается с шагом 0,5–4 кадра в секунду (шаг
   подбирается по длине: примерно 1200 отсчётов на фильм, не больше 6000).
   Для каждого кадра считаются метрики:

   | Метрика | Как считается |
   |---|---|
   | Резкость | дисперсия оператора Лапласиана по яркости |
   | Экспозиция | средняя яркость + доля пересвеченных/тёмных пикселей |
   | Контраст | стандартное отклонение яркости |
   | Насыщенность | colorfulness по Hasler–Süsstrunk |
   | Люди | `FaceDetector` на Android, `CIDetector` на iOS |
   | Движение | средняя абсолютная разница с предыдущим кадром |
   | Гистограмма | 64 бина по яркости, нормированные к сумме 255 |

2. **Отбор моментов** (`lib/src/core/highlight_selector.dart`):
   - каждая метрика нормализуется робастно (медиана + MAD), поэтому фильмы
     разной яркости и контраста сравнимы между собой;
   - метрики складываются в скор с настраиваемыми весами;
   - скор сглаживается по окну ±2 кадра, пик уточняется по исходному скору;
   - границы сцен определяются по расстоянию гистограмм (total variation > 0.45),
     клип не режется посреди сцены. Сцены короче `minSceneSec` не выделяются,
     иначе смонтированное видео с частой сменой плана не дало бы ни одного клипа;
   - пики отбираются с запретом пересечений и минимальным зазором.

3. **Нарезка.**
   - Android: `MediaExtractor` → `MediaCodec` (декодер) → EGL-рендер в
     `Surface` кодера → `MediaMuxer`. Кадры перекодируются, поэтому монтаж
     точный до кадра. Аудио AAC пробрасывается без перекодирования, остальные
     кодеки перекодируются в AAC.
   - iOS: `AVMutableComposition` + `AVAssetExportSession`, монтаж без
     перекодирования при совпадении формата.

## Структура

```
lib/                          приложение
  main.dart                   UI: выбор видео, прогресс, список моментов
  src/core/
    highlight_selector.dart   алгоритм отбора моментов (чистый Dart, покрыт тестами)
    clip_exporter.dart        вызовы нативного экспорта
  src/ui/moment_preview_card.dart
native/                       Flutter-плагин с нативным кодом
  android/.../VideoPlugin.kt    MethodChannel + анализ кадров
  android/.../VideoExporter.kt  MediaCodec/MediaMuxer + EGL
  ios/Classes/VideoPlugin.swift
  ios/Classes/VideoExporter.swift
test/                         тесты отбора моментов
```

Видео для проверки можно взять из любого короткого ролика: приложение
анализирует файл, а не подключается к плееру.

## CI

`.github/workflows/android.yml` собирает проект на `ubuntu-latest` (x86_64):
`flutter analyze`, `flutter test`, debug и release APK. Локально на aarch64
сборка Android невозможна — Google отдаёт `aapt2`/`zipalign` только под x86_64,
поэтому в Termux нужен CI или x86_64-хост.

Артефакты падают в `apk-debug` и `apk-release` (7 дней).

## Запуск

Нужен Flutter SDK 3.19+.

```bash
flutter pub get
flutter test
flutter run
```

Сборка:

```bash
flutter build apk --release
flutter build ios --release
```

Первый запуск на Android попросит разрешение на доступ к видео
(`READ_MEDIA_VIDEO`). Минимальная версия — Android 7.0 (API 24), iOS 13.

## Настройки отбора

Кнопка «настроек» в приложении меняет длину клипа (3–30 с), количество клипов
(1–15) и веса критериев: резкость, экспозиция, контраст, цвета, люди, движение.
Сортировка моментов идёт по времени, поэтому список клипов всегда
хронологический, а список трейлера — в порядке показа.

## Что проверено

- `dart analyze` чистый для всего слоя логики и плагина.
- `flutter test` — 11 тестов отбора моментов (пустой ввод, один кадр, выбор
  пика, лимит клипов, отсутствие пересечений, сортировка, границы видео, смена
  сцены, одинаковые гистограммы, пустая гистограмма, частая смена кадров).
- Kotlin-часть плагина компилируется `kotlinc` против `android.jar` (API 32).
- Swift-файлы проходят `swiftc -parse`. Расчёт метрик кадра (FrameData:
  резкость, насыщенность, движение, расстояние гистограмм) вынесен и прогнан
  на синтетических изображениях: полосы дают `sharpness=1.0`, плоский тёмный
  кадр — `0.0`, сумма нормированных бинов гистограммы — 255.

Не проверено в этой среде: сборка самого приложения через `flutter build` и
работа на реальном устройстве. Swift-код написан по API AVFoundation, но
компиляция требует macOS с Xcode.

## Ограничения

- Декодирование кадров идёт последовательно, поэтому анализ полного
  двухчасового фильма занимает минуты, а не секунды.
- Android-экспорт перекодирует видео в H.264. Исходники в H.265/VP9 будут
  конвертированы вниз по качеству.
- На iOS при перекодировании используется `AVAssetExportPresetHighestQuality`,
  битрейт из настроек там не применяется.
- Детектор лиц на Android (`FaceDetector`) — устаревший и ненадёжный на
  некоторых устройствах. Если он даёт сбои, метрика `faces` просто даёт
  нулевой вклад.
